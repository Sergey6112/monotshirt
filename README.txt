МОНОПРИНТ — конструктор футболок

Файлы:
- index.html — страница редактора
- styles.css — стили
- app.js — логика

Запуск:
Откройте index.html в браузере или загрузите папку на сервер, например:
https://mono-print.ru/monoshirt/index.html

Функции:
- перед / спина
- 6 цветов футболки
- загрузка PNG/JPG/WEBP/SVG
- перетаскивание принта
- масштабирование
- поворот
- добавление текста
- удаление / центрирование
- экспорт предпросмотра PNG
- адаптивная версия для телефона

Текущая версия использует качественный SVG-мокап футболки и не требует 3D-модели или внешних библиотек.
